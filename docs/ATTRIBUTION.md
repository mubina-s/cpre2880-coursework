# Attribution & Academic Context

This repository is a curated portfolio of selected coursework completed for **CPRE 2880 at Iowa State University**.

## Course Starter Code

Several CPRE 2880 labs were built using instructor-provided starter projects, headers, device-support code, and templates. Some selected source files therefore contain original course comments, function prototypes, or template structure.

Those comments and attributions have been retained where present rather than removed.

The files in this repository should be understood as **coursework implementations developed within that provided framework**, not as claims that every supporting component was authored from scratch.

## Public Portfolio Selection

The original coursework archive contains thousands of files, including:

- Code Composer Studio metadata
- Debug and build artifacts
- Compiled objects and binaries
- Device-support libraries
- Repeated copies of labs
- ZIP archives
- Putty logs
- Course documents
- Group-project workspace files
- Browser/tool metadata

Those files were intentionally excluded from this public portfolio.

The repository instead keeps selected lab source files that show progression in movement, UART, interrupts, object detection, ADC/IR sensing, ultrasonic sensing, and servo control.

## Final Project

The CPRE 2880 group final project is maintained separately at:

https://github.com/mubina-s/cybot-archaeology-survey-rover

This coursework repository is intended to complement that project rather than duplicate it.

## Public Sanitization

Local lab-network address references were removed from the public portfolio copies where encountered.

No build artifacts or full private course workspace are included.
